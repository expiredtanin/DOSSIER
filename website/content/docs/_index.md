DOSSIER ist eine Open-Source-Design-Suite für Architekten: klassisches
2D-Zeichnen und ein semantisches 3D-Gebäudemodell in einem Programm, daraus
abgeleitet saubere, normgerechte Pläne. Diese Seiten sind der
laufend aktualisierte Ist-Zustand — für die vollständige Rohfassung siehe
[STATUS.md](https://git.openbureau.ch/karim/DOSSIER-STANDALONE/raw/branch/master/STATUS.md)
im Repository.
