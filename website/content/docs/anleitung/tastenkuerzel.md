„Mod“ steht für **Cmd** auf dem Mac und **Strg** unter Linux und im
Browser. Alle Kombinationen lassen sich unter *Einstellungen →
Tastenkürzel* ändern: *Ändern* klicken, neue Kombination drücken, Esc bricht
ab. Einzeltasten (ohne Mod) gelten nur, solange kein Textfeld den Fokus hat.

## Allgemein

| Taste | Aktion |
|---|---|
| Mod+N | Neues Projekt (Menü der Desktop-App) |
| Mod+O | Öffnen (Menü der Desktop-App) |
| Mod+S | Speichern unter … (Menü der Desktop-App; bei gewählten 2D-Elementen: Teilen, siehe unten) |
| Mod+Z | Rückgängig |
| Mod+Shift+Z, Strg+Y | Wiederholen |
| Entf | Auswahl löschen |
| Mod+A | Alles auf der aktiven Ebene wählen |
| Mod+C, Mod+V | Elemente kopieren, einfügen |
| Mod+G, Mod+Shift+G | Gruppieren, Gruppe lösen |
| Esc | Befehl abbrechen |
| Enter, Leertaste | Bestätigen; ohne Befehl: letzten Befehl wiederholen |
| Tab | In die Befehlszeile; im Befehl: nächstes Feld |

## Werkzeuge (Einzeltasten)

| Taste | Werkzeug |
|---|---|
| `1` | Text |
| `2` | Linie |
| `3` | Kreis |
| `4` | Rechteck |
| `5` | Polylinie |
| `6` | Wand |
| `7` | Decke |
| `8` | Fenster |
| `9` | Tür |
| `0` | Raum |
| `m` | Verschieben |
| `s` | Spiegeln |
| `d` | Drehen |
| `q` | Messen |

## Bearbeiten

| Taste | Aktion |
|---|---|
| Mod+S | Teilen der gewählten 2D-Elemente |
| Mod+J | Verbinden der gewählten 2D-Elemente |
| Mod+Shift+U | Vereinigen (Boolean) |
| Mod+Shift+D | Abziehen (Boolean) |
| Mod+Shift+I | Schneiden (Boolean) |

Mod+S ist doppelt belegt: Sind 2D-Elemente gewählt, teilt es sie; sonst
speichert es. Wer das nicht mag, legt *Teilen* in den Einstellungen auf eine
andere Kombination.

## Maus

| Eingabe | Wirkung |
|---|---|
| Klick | wählen |
| Shift+Klick | Auswahl erweitern |
| Mod+Klick | nächstes Objekt unter dem Cursor wählen |
| Ziehen von links nach rechts | Rahmen: nur ganz Enthaltenes |
| Ziehen von rechts nach links | Rahmen: auch Angeschnittenes |
| Shift beim Zeichnen | Ortho (0°/90° bzw. Winkelraster) |
| Mausrad | zoomen |
| Rechtsklick | im Befehl bestätigen; auf einem Objekt: Kontextmenü |

## Befehlszeilen-Kürzel

Die getippten Kürzel (`w`, `pl`, `tr` …) stehen unter
[Befehlszeile](../befehlszeile/#alle-befehle). Eigene legt man unter
*Einstellungen → Allgemein → Befehlszeilen-Kürzel* an.
